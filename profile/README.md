## What is inside

- Connect Anything: 22 built-in source types, any API, and connectors written by AI
- Lake and Warehouse: one governed lake, and a warehouse with the DDL generated
- ETL/ELT and Workflows: AI-assisted transformations, pipelines that order themselves
- DataPrism BI and Semantic Models: live reports on governed models
- AI Minds: AI analysts that work on your own data
- Oda: an AI coworker on the desktop, in Excel and in VS Code

Data stays in ClickHouse on your servers. AI calls go only to zero-data-retention model
endpoints.
